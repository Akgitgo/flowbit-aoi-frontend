# Demo Video (3–5 Minutes)

Follow this script:

1. **Intro (10 sec)** — Purpose of the AOI creator.
2. **Start app** — Run `npm install && npm run dev`.
3. **Map load** — Show:
   - Base OpenStreetMap layer
   - WMS layer from NRW
4. **Draw AOI** — Draw polygon + marker.
5. **Persistence** — Refresh page, show AOIs remain.
6. **Tests** — Run `npx playwright test`.
7. **Closing** — Mention documentation + GitHub repo.
